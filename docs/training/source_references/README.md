# Source References

This folder holds source notes, transcript summaries, screenshots, article links, and other reference material for future GateKPT writing.

## Rules

- Keep raw source material separate from polished public copy.
- Summarize long articles or transcripts instead of copying them directly into public writing.
- Save related screenshots or images in this folder or a nearby `assets/` subfolder, then reference them from the source note.
- Mark unstable claims as `verify before publishing`.
- Prefer primary sources before publishing specific numbers, legal claims, policy claims, or company statements.
