# GateKPT Visual Engine – Keyboard Shortcuts

## Control

| Key | Action |
|-----|--------|
| **Esc** | Toggle fullscreen |
| **F11** | Toggle fullscreen (alt) |
| **Ctrl+Q** | Quit application |

## Display & UI

| Key | Action |
|-----|--------|
| **Ctrl+Shift+H** | Toggle HUD (frame time, RMS, peak, pitch) |
| **Ctrl+Shift+P** | Show preset menu |
| **Ctrl+Shift+D** | Show display picker |
| **Ctrl+Shift+F** | Toggle FFT visualization |

## Presets (via menu or config)

- **Default** – Standard oscilloscope settings
- **Wireless Safe** – Tuned for 100–300ms wireless display lag (longer persistence, higher smoothing release)

## In Preset Menu

- Click any preset to load it
- **Esc** to close menu
