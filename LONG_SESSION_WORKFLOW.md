# GateKPT Long Session Workflow

Goal: record for 2-3 hours without stopping, then cut the good moments afterward.

## Why

The short recorder is for making one take.

The long session mode is for practice, livestreams, camera tests, Elgato/webcam sessions, and long creative nights where stopping breaks the flow.

## Current Commands

Type these in GateKPT:

- `start capture`
- `clip this`
- `clip this chorus`
- `clip this guitar idea`
- `stop capture`
- `clip last`
- `open captures`
- `open clips`

## Flow

1. Open GateKPT Music OS.
2. Put the camera/Elgato/Windows Camera preview where you want it on screen.
3. Type `start capture`.
4. Play normally.
5. When something feels good, type `clip this` or `clip this hook`.
6. Keep playing.
7. Type `stop capture`.
8. Type `clip last` to cut a short MP4 around the most recent marker.

## Files

Long captures save here:

`C:\Users\Green Machine\Videos\GateKPT Screen Captures`

Marker logs save next to the long capture as:

`*.markers.txt`

Short clips save here:

`C:\Users\Green Machine\Videos\GateKPT Screen Clips`

## Elgato Direction

When the Elgato arrives, the first reliable setup should be:

- Elgato/webcam preview visible on the GateKPT screen.
- GateKPT visual stage moving behind/around the camera.
- `start capture` records the whole screen.
- `clip this` drops markers during the session.
- `clip last` cuts short clips after the session.

Do not overbuild a full camera studio before this loop is solid.
