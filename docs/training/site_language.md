# GateKPT Site Language

Use names that make the site obvious to a new visitor.

## Preferred Labels

- `Published writing`
- `Writing`
- `AI layers`
- `Read latest note`
- `Learn the layers`
- `All writing`

## Avoid In Visible UI

- `Field log`
- `Stack map`
- `Explore stack`
- `Research terminal`
- `Dashboard`
- `Hub`

These may exist in older code, filenames, route paths, or private notes. Do not reintroduce them as primary public labels unless Marcelo explicitly asks.

## Homepage Intent

The homepage should communicate two sides:

- One side: published writing.
- The other side: learn what happens underneath AI.

The labels should not make the user decode the site. They should immediately understand what they can read and what they can learn.
