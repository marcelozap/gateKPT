# GateKPT.ai Product Plan

`gatekpt.ai` is the public landing page for GateKPT.

It should be both:

- a credible product page for LinkedIn, GitHub, portfolio, and early users
- a lightweight interactive demo where visitors can try the music-to-visual-art idea

It should not become:

- the private MusicOS app
- a full DAW
- a trapped fullscreen visualizer
- a private project dashboard
- a Green Machine / trading surface

## Locked Structure

1. Hero
   - Explain GateKPT in one sentence.
   - Show a small visual preview.
   - Primary CTA: see the product.
   - Secondary CTA: try the visualizer.

2. Product Path
   - Landing page: understand the product.
   - Public demo: try a browser-safe visualizer.
   - Private app: create for real in the C#/.NET MusicOS.

3. How It Works
   - Play into the rig.
   - Shape the visual world.
   - Leave with assets.

4. Public Demo
   - Collapsed by default.
   - Opens only after a click.
   - Uses 2D canvas.
   - Has Exit demo.
   - Esc exits demo.
   - No upload, backend, AI call, or private files.

5. Product Sections
   - who it is for
   - inside the MusicOS
   - offer / pricing direction
   - technical stack
   - videos / proof
   - early access

## Public Demo Rules

- Keep it 2D.
- Keep it lightweight.
- Never autoplay microphone.
- Never trap the user.
- Never make it the whole website.
- Make the exit obvious.

## Desktop App Split

The private GateKPT MusicOS can have the serious 2D/3D renderer.

Website:

- accessible
- fast
- browser-safe
- shareable

Desktop app:

- C#/.NET
- local-first
- Focusrite / RC-505 aware
- 3D-capable later
- projector/performance focused

## One-Line Product Position

GateKPT turns live music creation into visual artwork, then helps the artist package the session into songs, captions, clips, and release-ready assets.
