# Connected Apps Layer

Purpose: let GateKPT support the artist day without becoming a productivity trap.

## Sources

Google Calendar:
practice blocks, recording blocks, release deadlines, appointments.

Gmail:
music opportunities, collabs, receipts, account notices, booking/admin.

Google Drive / Sheets:
lyrics, exports, setlists, budget, media folders, release plans.

Notion:
short artist protocols and project memory.

## GateKPT Use

Show:
- today in music
- current project
- next recording action
- next post/export action
- missing files

Do not show:
- giant task boards
- motivational copy
- fake music-business dashboards
- anything that interrupts performance

## Rule

Show the artist what to do next.

Less words.
More sound.
More image.
More action.
