# Tory-Primary Vocal Presets

GateKPT's first custom vocal lane is built around Tory Lanez as the primary reference:
glossy melodic R&B/rap, tuned-style, intimate, compressed, late-night, and emotional.

This is not trying to clone an artist. It is a practical GateKPT direction for Marcelo's
cover/video workflow:

```text
record -> choose vocal preset -> render -> compare -> use in post clip
```

## Presets

### Late Night Chrome

Primary lead preset. This is the center of gravity.

- Tory-style melodic R&B/rap lead
- tight, compressed, glossy
- intimate and bright
- short delay space
- slightly synthetic, still human

### Silk Synth

Lil Tecca `HVN ON EARTH` color.

- hook vocal as synth lead
- stronger polish
- smoother top
- wider movement
- best for simple melodic hooks

### Luna Pop

Rauw Alejandro color.

- Spanish/English pop vocal
- airy and rhythmic
- warm presence
- lighter delay
- best for Spanish covers and smooth pop sections

### Cloud Doubles

Background doubles and adlibs.

- wide
- softer
- more washed
- supports the lead
- best for harmony, adlibs, and chorus layers

### Raw Clean

Basic cleaned vocal before style choices.

- rumble cleanup
- steady level
- no obvious color
- useful for comparison

## Next Upgrade

Add real pitch-correction/autotune integration when GateKPT has a reliable local
pitch tool or plugin bridge. The current presets are tuned-style render chains using
