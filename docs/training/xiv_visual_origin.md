# XIV Visual Origin

GateKPT should keep the original XIV feeling: cinematic editorial technology.

## Source Feeling

- Night city.
- Wet glass.
- Reflective surfaces.
- A lone focused figure.
- Glowing visor or optical signal.
- Cyan as the main signal color.
- Restrained magenta in the environment.
- Amber only for small attention points.
- Quiet confidence, not loud cyberpunk.

## Current Anchor Asset

Use this as the primary visual reference:

`public/brand/xiv-visor-city-reference.png`

This image is the source of truth for atmosphere. It should influence the homepage, writing pages, and social imagery unless Marcelo provides a newer explicit reference.

## Avoid Drift

Do not make the site feel like:

- generic SaaS
- a dashboard template
- crypto or trading content
- gaming UI
- anime fantasy
- military or tactical interface
- decorative neon
- beige editorial blog
- random AI stock art

## Design Rule

The interface should feel like a research instrument around published writing, not a product marketing page.
